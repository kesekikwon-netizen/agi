# AGI 고고학 3D 사진측량 소프트웨어 UI/UX 시각 디자인 설계도
> **`mac-hgis (Strata)`의 한 줄 리본 디자인과 Agisoft & ContextCapture 엔진의 완벽한 결합**

본 문서는 실제 개발될 **`agi` 프로그램의 공식 시각 디자인 스크린샷 및 화면 인터랙션 명세**입니다.

---

## 1. 메인 작업 화면 (Main Workspace UI Mockup)

`mac-hgis`와 동일하게 상단 메뉴 트리를 없애고 **단일 한 줄 리본(One-Row Ribbon)**과 **3D 유구 지형 뷰포트**, **작업 트리**, **속성 패널**로 구성된 실제 프로그램 GUI 디자인입니다.

![AGI 메인 작업 화면 디자인 목업](/Users/kwon/.gemini/antigravity-cli/brain/d0774cbd-a023-49b6-b7b9-12cb412abf3a/agi_archaeological_photogrammetry_ui_png_1791897054407.jpg)

### 주요 시각적 구성 요소
1. **상단 한 줄 리본 막대 (One-Row Ribbon Bar)**:
   - `[조사]`: 새 조사 (`Ctrl+N`), 열기 (`Ctrl+O`), **저장 (`Ctrl+S`, 파란색 강조)**
   - `[사진·정렬]`: 사진추가 (`Ctrl+I`), **사진정렬 (`Ctrl+R`, 초록색 강조)**, 타깃인식 (`Ctrl+T`), 스케일 (`Ctrl+K`)
   - `[3D 복원]`: 고밀도점군 (`Ctrl+Shift+D`), 3D 메쉬 (`Ctrl+M`), 텍스처 (`Ctrl+X`)
   - `[도면화]`: **평면 정사영상 (`Ctrl+Alt+O`, 보라색)**, **토층 단면도 (`Ctrl+Alt+S`, 보라색)**, 등고선 (`Ctrl+Alt+C`)
   - `[내보내기]`: CAD(DXF), GeoTIFF, **검수·제출 (`Ctrl+E`, 주황색 강조)**
2. **좌측 작업 트리 패널 (`F9`)**:
   - `[블록 01] 트렌치 A구역` 하위의 사진 48장 정렬 상태, 기준점(GCP 4점), 스케일바(1.000m), 고밀도 점군(8.4M), 3D 메쉬, 등고선 레이어 트리 표시.
3. **중앙 3D 실시간 뷰포트 (`Ctrl+F11`)**:
   - 발굴 트렌치(목곽묘 피트) 3D 입체 점군 및 텍스처 메쉬.
   - 공중에 떠 있는 드론/카메라 촬영 궤적 피라미드와 시선 점선.
   - 현장 노란색 기준점 타깃(GCP)과 1.000m 스케일바.
4. **우측 속성/검사 패널**:
   - 선택된 사진의 초점거리, 서브픽셀 정합 오차(0.28 px), 스케일바 실측 오차(±0.2mm 극상) 표기.
5. **하단 상태줄**:
   - `작업 좌표계: EPSG:5186 (중부원점)`, 실시간 렌더링 프레임(60 FPS), 마우스 3차원 실측 좌표(X, Y, Z).

## 2. 고고학 특화 [토층 단면도 및 등고선 도면화] 화면

3D 유구 지형 위에 마우스로 **절단선 A-A'**를 그으면, 수직으로 잘린 흙의 층위(토층)가 1:1 사진 실측도로 즉시 렌더링되는 고고학 전용 화면입니다.

![AGI 토층 단면도 및 등고선 실측 뷰포트 목업](/Users/kwon/.gemini/antigravity-cli/brain/d0774cbd-a023-49b6-b7b9-12cb412abf3a/archaeological_stratigraphy_cad_view_1791897050104.jpg)

### 주요 시각적 구성 요소
1. **상단 평면 뷰포트 (1:1 Plan Orthomosaic & Contours)**:
   - 지표면 왜곡이 100% 보정된 정사영상 위에 **10cm 간격 노란색 등고선** 오버레이.
   - 단면을 자를 위치를 나타내는 붉은색 절단선 `A ●━━━━━━━━━━● A'`.
2. **하단 수직 토층 단면 뷰포트 (Vertical Soil Profile Section View)**:
   - A-A' 절단면의 깊이별 토층 경계선 및 층위 주석 표시:
     - `I층: 표토 / 경작토 (적갈색 사질점토)`
     - `II층: 흑갈색 점토 (목곽묘 매몰토 층위)`
     - `III층: 생토암반층`
   - 좌측 절대 표고축 (`EL. 35.0m ~ 33.0m`).
3. **상단 도면화 전용 툴바**:
   - `[단면선 지정]`, `[10cm 등고선 ON]`, `[AutoCAD DXF 내보내기]`, `[PDF 실측도면 인쇄]` 1클릭 조작.

## 3. 한 줄 리본 막대(Ribbon Bar) 버튼 상호작용 상세 표

| 버튼 그룹 | 버튼 라벨 | 단축키 | 화면 표시 색상 | 핵심 동작 및 대화상자 |
| :--- | :--- | :--- | :--- | :--- |
| **조사** | **새 조사** | `Ctrl+N` | 기본 어두운 회색 | 조사명, 5186/5187 좌표계, 저장 폴더 지정 팝업 |
| | **열기** | `Ctrl+O` | 기본 어두운 회색 | 기존 `.agi` 파일 탐색 및 열기 |
| | **저장** | `Ctrl+S` | **파란색 (핵심)** | 팝업 없이 원자적 저장 (제목 끝 `*` 해제) |
| **사진·정렬** | **사진추가** | `Ctrl+I` | 기본 어두운 회색 | 드론/카메라 현장 사진 다중 불러오기 |
| | **사진정렬** | `Ctrl+R` | **초록색 (핵심)** | 특징점 추출, 카메라 3D 위치 및 희소 점군 계산 |
| | **타깃인식** | `Ctrl+T` | 기본 어두운 회색 | 12-bit 원형/AprilTag 마커 0.1초 자동 검출 |
| | **스케일** | `Ctrl+K` | 기본 어두운 회색 | 마커 간 실측 거리(1.000m) 입력 후 1:1 보정 |
| **3D 복원** | **고밀도점군**| `Ctrl+Shift+D`| 기본 어두운 회색 | GPU(wgpu) 가속으로 수백만 개 입체 점군 생성 |
| | **3D 메쉬** | `Ctrl+M` | 기본 어두운 회색 | Screened Poisson 3D 표면 메쉬 생성 |
| | **텍스처** | `Ctrl+X` | 기본 어두운 회색 | 고해상도 사진 색상을 3D 표면에 베이킹 |
| **도면화** | **평면 정사영상**| `Ctrl+Alt+O` | **보라색 (고고학 특화)** | 왜곡 없는 1:1 수직 평면 정사도면 렌더링 |
| | **토층 단면도**| `Ctrl+Alt+S` | **보라색 (고고학 특화)** | A-A' 절단선 기준 **수직 토층 단면도 및 층위선 추출** |
| | **등고선** | `Ctrl+Alt+C` | 기본 어두운 회색 | 3D 지형 기반 10cm / 20cm 등고선 캐드 선 추출 |
| **내보내기** | **CAD(DXF)** | `Ctrl+Shift+E`| 기본 어두운 회색 | AutoCAD에서 바로 열리는 레이어별 2D/3D DXF |
| | **GeoTIFF** | `Ctrl+Shift+T`| 기본 어두운 회색 | 좌표가 포함된 무손실 지리참조 TIF 영상 |
| | **검수·제출**| `Ctrl+E` | **주황색 (강조)** | **5179 SHP + 도면 PDF + MANIFEST** 1클릭 패키징 |
